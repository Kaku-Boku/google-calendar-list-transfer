カレンダー一括登録

プライバシーポリシー

「カレンダー一括登録」（以下「本アプリ」）は、Google カレンダーのカレンダーリスト（購読しているカレンダーの表示名と色）を CSV でやり取りし、別のアカウントに一括登録するためのツールです。

アクセスするデータ

  • Google Calendar API の calendar.calendarlist スコープのみを使用します。 利用者のカレンダーリスト（購読しているカレンダーの ID、名前、表示名、色、権限、表示状態）の読み取りと、 表示名・色・表示状態の変更、カレンダーの購読追加を行います。
  • 予定（イベント）の内容、連絡先、メールなど、カレンダーリスト以外のデータにはアクセスしません。

データの保存と送信

  • 本アプリはサーバー側にデータベースを持ちません。取得したカレンダーリストと OAuth アクセストークンは利用者のブラウザーのメモリ上でのみ扱い、 ページを閉じると失われます。
  • Google Calendar API との通信は利用者のブラウザーから Google に直接行われ、第三者のサーバーを経由しません。
  • CSV ファイルは利用者が自分で保存・受け渡しするものであり、本アプリが収集・送信することはありません。
  • 利用者のデータを第三者に提供・販売することはありません。

アクセス権の取り消し

本アプリのアクセス権はいつでも Google アカウントの「第三者のアクセス権」から取り消せます。 本アプリの「ログアウト」ボタンは、ブラウザー内のアクセストークンを破棄し、Google に失効を要求します。 失効の成否を確実に確認したい場合は、上記の Google アカウント設定からアクセス権を確認・取り消してください。

Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から取得した情報の使用と他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定的使用の要件を含む）に準拠します。
